# Tier 2. Module 8 - Visual Analytics

## Lessons 09-11. Homeworks - Power BI. Data Preparation; Power BI dashboards; Overview of advanced Power BI capabilities

### Task description

1. Import the already prepared data from the [GO IT Data.xlsx](https://docs.google.com/spreadsheets/d/1-xjbu-wzVQuAua6PsqcX7ACwjPiYKWA0/edit?usp=sharing&ouid=110951581982879925383&rtpof=true&sd=true) file into Power BI and perform all the necessary transformations and calculations for further visualization.

You need to:
- find and eliminate errors, omissions and duplicates that could affect the analysis results,
- use various tools to change the format, structure or type of data according to the needs of the analysis.

2. Create a dashboard based on the data you have already prepared.

You need to create a report that will contain:
- a home page;
- a navigation bar (on each page);
- a filter bar (on each page);
- build several pages taking into account their business logic.

3. Add additional functionality to your report in PowerBI.

To do this:
- add Q&A;
- add a Decomposition Tree chart.
