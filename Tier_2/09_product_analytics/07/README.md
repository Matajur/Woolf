### Task description

You need to solve two problems.

#### Task #1

- Conversion rate — 0.45 (45%)
- Number of users in Stage 1 ($n$) = 8000.

#### Task #2

Compare the conversions of two test groups of an A/B test. Let's imagine that you are conducting an A/B test on two groups of users to determine whether the difference between the conversion rates is statistically significant. Test data:

- Group A: $p_A = 0,55$, $n_A = 12000$
- Group B: $p_B = 0,55$, $n_B = 12000$
