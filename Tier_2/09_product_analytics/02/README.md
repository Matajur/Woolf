# Tier 2. Module 9 - Product Analytics and Applied Statistics

## Lessons 02. Homework - Data collection and tools

### Task description

1. Choose a product that your product team will launch:

- a new social network (similar to Facebook or X (Twitter));
- a breakthrough online electronics store (similar to Rozetka);
- a service for selling tickets to warm countries.

2. Create a basic taxonomy for the selected product. Choose the main metrics, describe how you would calculate them.
3. Using one of the tracking plan templates from the outline (or develop your own), describe the tracking for the most important events when a potential customer first visits the product website (10-12 events will be enough).
