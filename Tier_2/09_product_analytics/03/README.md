# Tier 2. Module 9 - Product Analytics and Applied Statistics

## Lessons 03. Homework - Exploratory data analysis

### Task description

Use a [dataset](https://docs.google.com/spreadsheets/d/1-_Oaw12Sv-PIRkBe38NT-2LfOmU9KTlQ/edit?usp=sharing&ouid=113338271899322894929&rtpof=true&sd=true) with historical sales from an international store for exploratory analysis. This is best done in Tableau, Power BI, or Python.

1. Find seasonality and identify anomalies. Think about what groups you can divide your users into.
2. Visualize the data using the recommended visualization types.
3. Calculate descriptive statistics for the dataset as a whole and for the cohorts you have defined separately.
