# Tier 2. Module 9 - Product Analytics and Applied Statistics

## Lessons 05. Homework - A/B testing, advanced questions

### Task description

You are the product manager of a music streaming app called MelodyFlow. The app allows users to create playlists, discover new music, and listen to songs on their own schedule.

The app has two subscription types: free (with ads) and premium (without ads). The team has developed a new feature called Smart Playlist Recommendations, which uses artificial intelligence to automatically create personalized playlists based on the user’s listening history.

This feature is expected to improve user engagement and retention by making it easier for them to find music they like.

**Test design**:
- Control group (A): Users will not see the new Smart Playlist Recommendations feature.
- Test group (B): Users will have access to the new Smart Playlist Recommendations feature.

**Current data**:
- Daily Active Users (DAU): 20% of total users log in daily.
- Total users: 1,000,000 users (600,000 free, 400,000 premium).
- Average session duration: 15 minutes per session.
- Baseline retention rate (7-day): 41%.
- ARPPU for the last month: $25

**Your task is to calculate the sample size for a binomial metric.**

**Hypothesis**: Implementing Smart Playlist Recommendations will increase customer retention on day 7.

Determine the MDE, significance and power levels, select the test type, and calculate the number of users needed for a statistically significant result.
