# Tier 2. Module 7 - Design and Analysis of Algorithms

## Lesson 01. Algorithm Analysis. Divide and Conquer Strategy

### Task 1 (required) - Finding the maximum and minimum elements

Implement a function that finds the maximum and minimum elements in an array using the divide-and-conquer method.

### Acceptance criteria

- The function accepts an array of numbers of arbitrary length.
- A recursive approach is used.
- A tuple of values ​​(minimum, maximum) is returned.
- The complexity of the algorithm is O(n).

### Task 2 (optional) - Finding the k-th smallest element

Implement an algorithm to find the k-th smallest element in an unsorted array using the Quick Select principle.

### Acceptance criteria

- The function must accept an array of numbers and a number k.
- The pivot approach must be used.
- The array must not be completely sorted.
- The expected complexity in the average case should be O(n).
